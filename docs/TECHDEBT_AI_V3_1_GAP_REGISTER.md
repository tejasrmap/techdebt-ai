## Status Legend

Every gap uses strictly one of the following statuses:
- `NOT STARTED` — Identified in Phase 0 audit; implementation not yet started.
- `IN PROGRESS` — Implementation actively underway.
- `IMPLEMENTED` — Code written; awaiting automated test verification.
- `TESTED` — Automated unit/integration tests written and passing locally.
- `VERIFIED` — End-to-end regression, CI/database checks, and acceptance criteria confirmed.
- `BLOCKED` — Blocked on external dependency or credential (with documented reason).
